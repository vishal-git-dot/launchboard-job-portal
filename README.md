# Launchboard

</div>

---

## About

Launchboard is a mini job and internship portal that connects students with career opportunities. Students can explore openings, search and filter listings, submit applications with resumes, and track application progress. Organizations can manage job posts and review applicants through a dedicated workspace.

Built with **PHP, MySQL, HTML, CSS, and JavaScript**, Launchboard features a responsive interface and thoughtfully designed light and dark themes.

## Features

### For Students
- **Account access** — Register and sign in securely.
- **Discover opportunities** — Browse available jobs and internships.
- **Search and filters** — Find opportunities by keyword, category, and location.
- **Opportunity details** — Review descriptions, requirements, and deadlines.
- **Apply online** — Submit applications and upload a resume.
- **Application tracking** — Check the status of submitted applications.

### For Organizations
- **Opportunity management** — Create and manage job or internship listings.
- **Applicant review** — View applications submitted for posted opportunities.
- **Status updates** — Update application progress, such as under review or accepted.

### Interface & Security
- **Responsive design** — Layouts adapt to desktop, tablet, and mobile screens.
- **Light and dark themes** — Switch themes with the selected preference saved locally.
- **Clear feedback** — Form validation and visible interaction states.
- **Secure foundations** — Password hashing, prepared database statements, role checks, and request protection.
